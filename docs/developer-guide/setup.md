# Setup

## Development Environment
1. Clone or copy the project.
2. Install PHP 7.4+, Composer, Node.js.
3. Run `composer install`.
4. Set up local database.
5. Configure `.env` for development.
6. Run `php spark serve` for local server.

## IDE Setup
- Use VS Code with PHP extensions.
- Follow .windsurfrules for AI assistance.

## Testing
- Run tests with `php spark test`.
- Add tests for new features.

## Deployment
- Use CI4 deployment guides.
- Ensure environment configs.
