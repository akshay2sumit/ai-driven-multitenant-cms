# Contribution

## How to Contribute
1. Fork the repo.
2. Create a branch for your feature.
3. Follow coding standards.
4. Add tests.
5. Submit PR.

## Guidelines
- Follow .windsurfrules.
- Document changes.
- Update ADRs for decisions.

## Code Review
- All PRs reviewed.
- CI checks must pass.

## Issues
- Report bugs with details.
- Suggest features with rationale.
