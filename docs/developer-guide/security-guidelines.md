# Security Guidelines

## Best Practices
- Enable CSRF protection.
- Use HTTPS.
- Hash passwords.
- Validate and sanitize inputs.
- Limit file uploads.

## AI Security
- Secure API keys in environment.
- Rate limit AI requests.
- Audit AI outputs for safety.

## Access Control
- Role-based permissions.
- Least privilege.

## Vulnerabilities
- Protect against XSS, SQL injection, CSRF.

## Monitoring
- Log security events.
- Regular audits.
