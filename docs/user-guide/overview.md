# User Guide: Overview

## Welcome to Ai-cms
Ai-cms is an AI-integrated Content Management System that helps you create, manage, and publish content with intelligent assistance.

## Key Features
- **AI-Powered Content**: Get suggestions for articles, images, and more.
- **Easy Management**: User-friendly interface for content creation.
- **Multi-Tenant Support**: Manage multiple sites or sections.
- **Dashboard Monitoring**: Visual project status via dashboard.
