# Getting Started

## Prerequisites
- Web server (Apache/Nginx) with PHP 7.4+
- MySQL or PostgreSQL database
- Composer for dependency management

## Installation
1. Install CodeIgniter 4 in a new directory.
2. Copy the Ai-cms structure into the CI4 root.
3. Run `composer install` to install dependencies.
4. Configure `.env` file with database credentials.
5. Run migrations: `php spark migrate`.
6. Access the application at your domain.
