# Common Tasks

## Creating a New Page
1. Access your tenant's admin interface at `/t/{your-tenant}/admin`
2. Click "New Page"
3. Enter a title and content
4. Click "Save"

   **Note**:
   - Only basic text formatting is supported
   - No images or media can be added
   - Pages are saved immediately (no draft/published states)

## Editing Pages
1. Navigate to the page list
2. Click "Edit" next to the page you want to modify
3. Make your changes
4. Click "Save" to update

## Managing Content
- **View All Pages**: See a list of all pages in your tenant
- **Search**: Basic title-based search
- **Delete**: Remove pages (no trash/recycle bin)

## Important Notes
- No version history is maintained
- No automatic backups
- No user management in this version
- No media uploads or rich text editing

## Troubleshooting
- **Page not found**: Verify the URL includes the correct tenant identifier
- **Changes not saving**: Check for validation errors
- **Other issues**: Contact your system administrator
