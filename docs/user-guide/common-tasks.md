# Common Tasks

## Creating Content
1. Log in to the admin panel.
2. Navigate to Content > New Article.
3. Use AI suggestions for title and body.
4. Save and publish.

## Managing Users
1. Go to Users section.
2. Add new users with roles (admin, editor, viewer).
3. Assign permissions.

## Viewing Analytics
- Access Reports > Analytics for content performance.

## Backup Data
- Use the backup feature in settings to export data.

## Troubleshooting
- Check logs in `writable/logs/`.
- Refer to [FAQ](faq.md).
