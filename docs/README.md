# Documentation Hub

## Overview
This directory serves as the central hub for all project documentation, categorized for different audiences and purposes.

## Structure
- **user-guide/**: End-user documentation (non-technical)
- **developer-guide/**: Technical guides for developers
- **architecture/**: System design and architecture docs
- **adr/**: Architecture Decision Records
- **llm-handoff/**: Context for new AI chats/agents
- **agent-helper-guide.md**: Guide for AI agents on folder structure and usage

## Guidelines
- All documentation must stay in sync with code.
- Use Markdown for readability.
- Update docs with code changes.
